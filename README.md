As informações de como executar e como funciona está presente em seu respectivo documento no diretório /docs.

Mas, para facilitar, para rodar o módulo desejado, entre no diretório, e com o docker desktop rodando, execute: docker compose up --build

Lembrando, para que o A2 local funcione, esse módulo precisa estar rodando alimentando o barramento (kafka) com dados dos QR.
